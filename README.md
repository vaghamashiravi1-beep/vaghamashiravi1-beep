### 📦 Key Architectural Showcases

```
┌────────────────────────────────────────────────────────────────────────┐
│                        FEATURED CASE STUDIES                           │
└────────────────────────────────────────────────────────────────────────┘
```

#### 1. [SubTrack](https://github.com/vaghamashiravi1-beep/SubTrack) — Offline-First Fintech Tracker & Smart Statement
> **Architecture**: Pure Monorepo with strictly isolated `@subtrack/shared` domain logic + React Native (Expo SDK 58) client.
- **Key Engineering Highlights**:
  - **Zero-Clock Skew Calendar Math**: Leap-year aware anchor date algorithms with pure string arithmetic (`YYYY-MM-DD`).
  - **Deterministic Safe-Area & Insets Engine**: Pixel-perfect cross-platform rendering across dynamic notch/island variations.
  - **Fintech Micro-UI**: Big amount grouping (`formatInr`), dynamic 12-month on-time payment track record, masked card rendering (`•••• 4821`).
  - **Zero-Cloud Privacy Guarantee**: 100% on-device SQLite data layer without telemetry or external tracking.

#### 2. Enterprise Contractor Field Engine (Production)
> **Architecture**: Multi-module Java/Kotlin hybrid Android app with heavy local persistence.
- **Key Engineering Highlights**:
  - Offline sync engine reconciling conflicting record edits against enterprise cloud endpoints.
  - Custom UI library with DataBinding/ViewBinding and zero 3rd-party UI overhead.
  - Mixed reactive streams bridge (RxJava2 Observables gracefully converted to Kotlin Coroutines & Flows).
